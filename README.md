# Car Rental System

A web-based car rental system built using **ASP.NET Core MVC** with **Blazor** and **Razor Pages**. This application allows users to update their profiles, browse available cars, rent vehicles for a selected period, and provides administrators with full CRUD functionality.

## Features

- **User Management**: Users can update their profile details.
- **Car Browsing**: View available cars for rent.
- **Car Rental**: Rent cars for a specified date range.
- **Admin Panel**: CRUD operations for managing cars, users, and rentals.

## Technologies Used

- **ASP.NET Core MVC**
- **Blazor**
- **Razor Pages**
- **Entity Framework Core**
- **SQL Server**
